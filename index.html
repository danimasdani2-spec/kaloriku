📖 Cara Mendapatkan API Key (untuk pemula)

Gemini (gratis):
  1. Klik link ini: aistudio.google.com/app/apikey
  2. Login dengan akun Google Anda.
  3. Klik tombol "Create API key", lalu salin kodenya.
  4. Tempel kode itu di kolom Gemini Key 1 di bawah, lalu Simpan.
Groq (cadangan, gratis):
  1. Klik link ini: console.groq.com/keys
  2. Daftar / login, klik "Create API Key", salin kodenya (diawali gsk_).
  3. Tempel di kolom Groq API Key di bawah, lalu Simpan.
